Una aplicación web interactiva y educativa diseñada para explorar los colores, la historia y la composición de la Bandera de México. Este proyecto fue construido como una práctica avanzada de desarrollo Frontend (Vanilla JavaScript, HTML y CSS) con un fuerte enfoque en UI/UX y diseño responsivo.

🔗 **[¡Mira el proyecto en vivo aquí!](https://ibraymortizmartinez.github.io/intro-webapp-mexico/)**

---

## ✨ Características Principales

* **Diseño UI/UX Moderno:** Interfaz construida con la tendencia de diseño **Glassmorphism** (efecto cristal) usando `backdrop-filter` y variables CSS dinámicas.
* **Tarjetas Interactivas 3D:** Animaciones de volteo (Flip Cards) en 3D que revelan el significado histórico de cada color de la bandera.
* **Manipulación de Color en Tiempo Real:** * Sliders interactivos para ajustar la opacidad de los colores.
    * Conversión de formatos de color instantánea (HEX, RGB, HSL).
    * Selector de temas para cambiar entre la paleta Oficial, Pastel y Neón.
* **Modo Oscuro (Dark Mode):** Transición suave entre temas claro y oscuro, con persistencia de datos usando `localStorage`.
* **Micro-interacciones y Efectos:**
    * Efectos de sonido (Web Audio API) al interactuar con los botones.
    * Animación de confeti al restaurar los colores o exportar.
    * "Copiar al portapapeles" con notificaciones Toast.
* **Exportador de Código:** Genera automáticamente el código CSS de los colores actuales para integrarlo en otros proyectos.
* **100% Responsivo:** Adaptado para funcionar perfectamente en dispositivos móviles, tablets y monitores de escritorio.

## 🛠️ Tecnologías y Herramientas

* **Estructura:** HTML5 semántico.
* **Estilos:** CSS3 (Flexbox, CSS Grid, animaciones `@keyframes`, variables CSS).
* **Lógica:** Vanilla JavaScript (ES6+).
* **Almacenamiento:** `localStorage` para guardar las preferencias del usuario.
* **Librerías de terceros:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) para efectos visuales.

## 🚀 Instalación y Uso Local

Si deseas correr este proyecto en tu máquina local:

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/ibraymortizmartinez/intro-webapp-mexico.git](https://github.com/ibraymortizmartinez/intro-webapp-mexico.git)

2. Navega a la carpeta del proyecto:
    cd intro-webapp-mexico

3. Abre el archivo index.html en tu navegador de preferencia o utiliza un servidor local como la extensión "Live Server" en VS Code.
